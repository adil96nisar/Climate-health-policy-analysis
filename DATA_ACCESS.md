# Data access and redistribution

CHPG-O was developed from Bangladesh news, national-policy documents, and WHO/external normative or update sources. Not every source file can be redistributed in a public code repository.

The broader project inventory contains 1,298 collected news PDFs (2014-2024) and 178 deduplicated/relevance-filtered indexed source entries. The post-hoc three-layer integration used eight verified representative news items from five source organisations; it was not a fresh end-to-end re-indexing of all 1,298 PDFs.

`scopeComplete=true` means the predefined source set for that case was searched completely. It does not mean every possible Bangladesh policy source was exhausted.

Raw newspaper PDFs and policy PDFs without established redistribution permission are not included in the public repository. The accompanying reproducibility package preserves structured inputs, source identifiers, bounded source mappings, machine-result summaries, and formal verification artifacts.
